**ALTCHA_HMAC_KEY** — это секретная строка, используемая для подписи данных (HMAC). Она гарантирует, что challenge (загадка), который решает пользователь, был создан именно вашим сервером и не был подделан злоумышленником.

Для этой инструкции (и вообще для ALTCHA) там должна быть **длинная, случайная строка с высокой энтропией**. Желательно использовать 64 символа в HEX-формате (или 32 байта), чтобы исключить любые попытки подбора.

Вот способы сгенерировать криптостойкий ключ в вашем окружении.

---

### 1. Генерация через Linux Shell (Bash / Docker)

Самый простой и надежный способ, так как утилита `openssl` есть почти в любом Linux-дистрибутиве и Docker-образе.

#### Вариант A: OpenSSL (рекомендуемый)

Генерирует 32 байта случайных данных и переводит их в hex-строку (64 символа). Безопасно для вставки в `.env` файлы (нет спецсимволов).

```bash
openssl rand -hex 32

```

**Результат будет примерно такой:**
`a1b2c3d4e5f678901234567890abcdef1234567890abcdef1234567890abcde`

#### Вариант B: PHP (раз уж у вас Yii2)

Если вы внутри PHP-контейнера и там нет openssl (что вряд ли, но бывает):

```bash
php -r "echo bin2hex(random_bytes(32)); echo PHP_EOL;"

```

#### Вариант C: /dev/urandom (Native Linux)

Если совсем нет утилит, используем системный генератор:

```bash
cat /dev/urandom | tr -dc 'a-zA-Z0-9' | fold -w 64 | head -n 1

```

### 2. Генерация через Ansible

В Ansible есть встроенные механизмы для генерации паролей и секретов. Это удобно при деплое, чтобы ключ генерировался "на лету" и сохранялся.

#### Вариант A: Ad-hoc команда (просто получить строку)

Вы можете запустить это локально, чтобы получить строку для копипаста:

```bash
ansible localhost -m debug -a "msg={{ lookup('password', '/dev/null length=64 chars=hexdigits') }}"

```

* `length=64`: длина строки.
* `chars=hexdigits`: использовать только цифры и буквы a-f (hex), что безопаснее для конфигов, чем `ascii_letters` (избегаем кавычек и спецсимволов).

#### Вариант B: Внутри Playbook (для авто-деплоя)

Если вы хотите, чтобы Ansible сам создал файл `.env` или `params-local.php` с ключом:

```yaml
- name: Generate ALTCHA secret
  set_fact:
    altcha_secret: "{{ lookup('password', 'credentials/altcha_secret_file length=64 chars=hexdigits') }}"

- name: Write secret to Yii2 params
  lineinfile:
    path: /path/to/project/common/config/params-local.php
    regexp: "'altcha.hmacKey'"
    line: "    'altcha.hmacKey' => '{{ altcha_secret }}',"

```

* **Важно:** Плагин `lookup('password', 'path/to/file ...')` идемпотентен. Он сгенерирует ключ один раз, сохранит его в локальный файл `credentials/altcha_secret_file` и при следующих запусках будет брать тот же самый ключ. Это критично, иначе при каждом деплое у вас будут инвалидироваться старые challenge.

---

### 3. Куда вставлять (по вашей инструкции)

Согласно вашему файлу, код ожидает ключ в параметрах приложения.

1. Скопируйте сгенерированную строку (например, `f4a7d...`).
2. Откройте `common/config/params-local.php` (этот файл обычно в `.gitignore`).
3. Вставьте ключ:

```php
return [
    // ...
    'altcha.hmacKey' => 'ВСТАВИТЬ_СГЕНЕРИРОВАННЫЙ_КЛЮЧ_СЮДА',
];

```

Либо, если вы используете `.env` (через `getenv` в инструкции), добавьте в файл `.env`:

```bash
ALTCHA_HMAC_KEY=ВСТАВИТЬ_СГЕНЕРИРОВАННЫЙ_КЛЮЧ_СЮДА

```
